# QR Code Generator

A simple and responsive QR Code Generator developed using **HTML, CSS, and JavaScript**. This application allows users to generate QR codes for any text or URL instantly.

## 🚀 Features

- Generate QR codes for text and URLs
- Simple and user-friendly interface
- Responsive design
- Clear input functionality
- Download generated QR code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QR Code API

## 📂 Project Structure

```
QR-Code-Generator/
│── index.html
│── style.css
└── README.md
```

## ▶️ How to Use

1. Open the application.
2. Enter any text or URL.
3. Click the **Generate** button.
4. The QR code will be displayed.
5. Click **Download QR Code** to save it.
